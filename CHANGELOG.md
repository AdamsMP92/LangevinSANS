# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-11-16

### Added

- stable analytical Langevin function and closed-form first and second moments;
- reversible field-dependent magnetization and correlation-tensor curves;
- magnetic unpolarized and polarization-averaged spin-flip SANS backends;
- detector maps, azimuthal `I(q)`, pair-distance functions, and field scans;
- physical model documentation, scientific tests, Pixi environment, and CI;
- citation metadata for a future Zenodo archive.
